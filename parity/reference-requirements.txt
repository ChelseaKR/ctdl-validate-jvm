# version and by artifact hash.
#
# The pin is a released, immutable PyPI artifact rather than a branch, because
# the expectations in parity/expected/ are only meaningful against a rule set
# that cannot change underneath them.
#
# It moved from 0.1.0 to 0.2.1 with the change that ported --resolve, which is
# what 0.2.1 added to the rule core; parity/PROVENANCE.md records what the move

# tools/reference_gap.py says by how much, so this is the newest rule set the
# port can be held to byte for byte.
#
# Bumping this pin is a deliberate act: install the new version, rerun
# tools/generate_expectations.py, and review the diff to parity/expected/ as
# the change to the rule set that it is.
#
#   pip install --require-hashes -r parity/reference-requirements.txt
#
